Все материалы получены из рендера собранной Windows-демки. Проверочный режим подготавливает прогресс, чтобы показать открытые действия. Для демонстрации обмена задаётся последовательность выпадения кирок; покупки, расчёт результата и анимации используют существующий код. Это демонстрация возможностей, а не запись времени прохождения с нуля. Внешних наложений, составленного интерфейса и увеличения разрешения нет. Ролик без звука. При кодировании сохраняются записанные интервалы кадров.

## Повторение

1. Собрать Windows-демку через **Mine Loot → Build Windows demo** в Unity 2022.3.47f1.
2. Запустить из корня проекта:

   ```powershell
   Start-Process '.\Builds\Windows\MineLoot.exe' -ArgumentList '-demoSmokeTest', '-demoStoreCapture', '-demoOutput', "$PWD\Logs", '-logFile', "$PWD\Logs\runtime-store.log" -WindowStyle Hidden -Wait
   ```

   Флаг записи работает только с `-demoSmokeTest`. Данные игрока не читаются и не меняются. JPEG-кадры и интервалы появляются в `Logs/store-frames/`; снимки записываются тем же smoke-сценарием. Снимки карточки лежат в `Logs/unity-desktop-mine.png` и `Logs/unity-desktop-roulette-choice.png`, производства — в `Logs/unity-desktop-production.png`.

3. Установить Pillow и получить FFmpeg из официального источника. В текущей среде использованы Pillow и Windows-бинарник из колеса [imageio-ffmpeg 0.6.0](https://pypi.org/project/imageio-ffmpeg/0.6.0/), установленного без зависимостей в игнорируемую тестовую папку. Бинарник и пакеты не входят в Git.
4. Передать кодировщику путь к FFmpeg:

   ```powershell
   python Tools/encode-store-video.py Logs/store-frames --ffmpeg 'C:\path\to\ffmpeg.exe' --output Docs/store/gameplay.mp4
   ```

   Скрипт проверяет размеры исходников, монотонность времени, длительность, H.264, размер файла и полное декодирование результата. Отчёт — `Logs/store-video-check.json`. Исходные тестовые кадры и отчёты не входят в Git.

## Проверка сохранённого видео

28 октября 2026 ролик скачан штатной кнопкой консоли после обработки, файл **14255025**. Полученный MP4: H.264 High, 1280×720, 30 кадров/с, 18 секунд, 1 862 937 байт. FFmpeg декодировал все 540 кадров с кодом завершения 0. SHA-256: `b6ab61fb6112bfec7943ffd100322e53844eef78678eaba92ce5b687dd9bb535`.

Встроенный предпросмотр сначала сообщил об ошибке воспроизведения, затем показывал чёрное окно. Проигрывание в самом интерфейсе консоли остаётся ручной проверкой; причина этого поведения не установлена.
