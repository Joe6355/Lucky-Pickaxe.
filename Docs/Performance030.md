# Оптимизация 0.30

Убрано обновление скрытых улучшений, наград, списка чар и боковой карточки. При открытии соответствующего раздела он получает актуальные данные прежним путём. Блеск зачарованной кирки обновляется и вне страницы чар.

Неподвижные блоки и закрытые сундуки рулетки больше не получают одинаковые параметры каждый кадр. Затухающий удар всё ещё возвращает масштаб и цвет к исходным значениям; состояние потерянного сундука обновляется при смене доски. Пулы частиц сохранены: одинаковые осколки и пыль используют общие меши, ссылки на трансформы и рендереры кешируются. Частицы и анимации не урезаны.

Tiny5 используется только редактором для обложки. Файл и его лицензия перемещены из Resources в Editor/Fonts с сохранением GUID; редактор загружает шрифт через AssetDatabase. Шрифты интерфейса PT Sans и его текстуры не уменьшались.

## Локальный замер CPU

Windows Development Player, Unity 2022.3.47f1, 480×960, отдельный тестовый прогресс, одна рабочая среда. Базовая сборка уже включает панель звука, но ещё не включает оптимизации. Медиана пяти серий: по 500 принудительных обновлений интерфейса с изменением кошелька и по 1000 вызовов обновления неподвижной рулетки. Разогрев — 30 вызовов. Метод — `DemoSmokeCheck.BenchmarkPresentation`.

| Показатель | До | После |
|---|---:|---:|
| Обновление интерфейса, мс/вызов | 0.071776 | 0.022769 |
| Неподвижная рулетка, мс/вызов | 0.008763 | 0.000184 |
| Уникальные меши трёх сцен | 438 | 237 |

В этом замере время обновления интерфейса уменьшилось на 68.3%, а число мешей — на 45.9%. Это CPU-замер выбранных методов, не прирост FPS всей игры и не скорость загрузки через сеть Яндекса. Одиночные значения времени Awake в JSON не используются для заявления ускорения старта. Счётчик выделений памяти в этой среде вернул нули и не используется.

Исходные отчёты — `Logs/performance-before.json`, `Logs/performance-after.json`; они исключены из Git. Для повторения после сборки: запусти Windows-плеер с `-demoSmokeTest -demoBenchmark -benchmarkTag after -demoOutput "<папка отчётов>"`. Замер не затрагивает сохранение игрока. Для сравнения до оптимизации нужен прежний плеер; текущая сборка содержит оптимизации.

## Размер и загрузка

Архив 0.30.0 — 6615918 байт, в 0.29 — 6644067 байт. Разница — 28149 байт (0.42%). Уменьшение небольшое; новая версия также добавляет панель и сохранение настроек. Распакованный размер — 6803010 байт. Проверка данных архива подтверждает отсутствие Tiny5 и наличие обоих PT Sans.

Gzip, кеширование данных и распаковка загрузчиком сохранены. Холодная загрузка через реальную сеть Яндекса и FPS на физических устройствах не измерялись. Локальный CPU-тест не подтверждает их ускорение.
