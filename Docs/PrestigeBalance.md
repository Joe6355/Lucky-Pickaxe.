# Повторное прохождение и престиж 0.34

100 воспроизводимых последовательностей, seed 6355–6454, по четыре шахты до уровня 50. Модель: 6 ударов в секунду вне рулетки, 3 секунды на розыгрыш, без времени на размышление. Бот покупает снаряжение и производство по правилам основной симуляции, забирает контракты и цели, использует раскрытый обсидиан и богатые жилы. Офлайн-доход в этой проверке не используется.

После каждого достижения уровня 50 подтверждается один престиж. Каждая новая шахта даёт +15% опыта, максимум +75%; поток опыта добавляет ещё +25%. Дробный опыт переносится между начислениями. Приоритет постоянных покупок: запас монет, каменный старт, верный удар, мастер чар, запас прочности, поток опыта, рудная удача; затем остальные доступные узлы из 21. Награда за сброс — 8–20 кристаллов, все узлы стоят 84 кристалла. Цели и контракты сохраняются между шахтами; старые разовые награды не повторяются.
