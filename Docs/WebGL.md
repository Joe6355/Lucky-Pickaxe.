# Браузерная сборка 0.17

Unity **2022.3.47f1** (`88c277b85d21`), WebGL Build Support этой же версии. Модуль установлен в текущей рабочей среде; версия редактора не менялась.

## Сборка

Меню **Mine Loot → Build Yandex Games WebGL** либо из PowerShell в корне проекта:

```powershell
& 'C:\Program Files\Unity\Hub\Editor\2022.3.47f1\Editor\Unity.exe' -batchmode -quit -buildTarget WebGL -projectPath $PWD.Path -executeMethod DemoTools.BuildWebGL -logFile "$PWD\Logs\webgl-build.log"
```

Результат — `Builds/WebGL/` и `Builds/LuckyPickaxe-YandexGames.zip`, с `index.html` непосредственно в корне архива. Сборка Release, без потоков, со сжатием Gzip и распаковкой в загрузчике Unity. Шаблон — `PROJECT:LuckyPickaxe`. Windows-сборка продолжает собираться прежним методом `VerifyAndBuild`. Бинарные сборки исключены из Git.

## Локальная проверка

Установить Node.js с npm и Microsoft Edge, затем в корне проекта:

```powershell
npm --prefix Tools install --ignore-scripts
npm --prefix Tools run check
npm --prefix Tools run preview
```

Прокси откроет `https://localhost:8126`. Он использует локальный самоподписанный сертификат. Во втором терминале:

```powershell
npm --prefix Tools run check:browser
```

Браузерный тест использует отдельный временный профиль в `_test-concept/`, который не читает данные обычного браузера. Фикстура отсутствия на десять минут подставляется только в этот профиль; системные часы не меняются. Скрипт по умолчанию запускает Edge без окна; для установленного Chrome можно передать переменную `WEBGL_CHANNEL=chrome`. Проверка Chrome в текущем прогоне не выполнялась.

`Tools/package.json` закрепляет `@yandex-games/sdk-dev-proxy` 0.0.2 и Playwright 1.62.1. Dev-прокси — официальная тестовая среда с моками SDK, без настоящего аккаунта, рекламы и серверных сохранений. Описание режима — [документация Яндекса](https://yandex.ru/dev/games/doc/ru/concepts/local-launch).

Для демонстрации без SDK разрешён явный параметр `?local=1` только на `localhost`, `127.0.0.1` или `[::1]`. Нужен обычный HTTP-сервер файлов `Builds/WebGL/`; страница показывает пометку локальной демоверсии. На внешнем домене этот параметр не отключает SDK.

## Интеграция

- SDK загружается через `/sdk.js`, затем вызывается `YaGames.init()`. Его файл в проект не скачивается. Это вариант для загрузки архива на сервер Яндекса — [подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about).
- После создания интерфейса и первого кадра Unity сообщает готовность JavaScript-мосту. Только после готовности SDK, Unity и интерфейса скрывается наша загрузочная панель и один раз вызывается `LoadingAPI.ready()` — [Game Ready](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events).
- До готовности SDK игра заблокирована загрузочным экраном. Ошибка подключения показывает кнопку повторной загрузки; ложный сигнал готовности не отправляется.
- `game_api_pause` / `game_api_resume`, видимость страницы и её фокус учитываются независимо. Снятие одной причины не возобновляет игру, пока остаётся другая. Подписки используют `ysdk.on`, очистка — `ysdk.off` — [события SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events).
- Пауза останавливает ручной ввод, удержание руды, производство, жилу, барабаны, удары кирок, эффекты мира и звук. Настройка звука пользователя не меняется. Оплаченный бросок сохраняется и продолжается; при возвращении рассчитывается прежняя офлайн-награда для ручного получения.
- `pagehide` сохраняет состояние до паузы. Полный JSON сначала попадает в синхронный журнал `localStorage`, затем в существующие PlayerPrefs с резервной копией. Ключи и формат v11 сохранены; при неверном журнале проверяются PlayerPrefs. Это локальное сохранение данного сайта, без авторизации и облака.

Явная разметка `GameplayAPI.start/stop` не добавлялась. Платежи и облачная синхронизация не подключены.

## Наградное видео 0.17

В окне склада есть **Забрать** и **Забрать ×2 за видео** с заранее показанной суммой. Обычный путь не требует рекламы. Видео доступно при поддержке SDK, непустом складе и достаточном месте для полной удвоенной суммы; в Windows и режиме `?local=1` кнопка отключена.

Вызов проходит через существующие `BrowserPlatform`, `.jslib` и `platform.js` к `ysdk.adv.showRewardedVideo({ callbacks })`. Только `onRewarded` разрешает `MineGame.ClaimOffline(true)`: кошелёк и статистика увеличиваются на два текущих остатка, склад очищается и полный JSON сразу сохраняется. `onClose` без подтверждения, `onError` и отказ открытия ничего не начисляют и оставляют обычное получение. Источник контракта SDK — [наградная видеореклама Яндекса](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv#ysdkadvshowrewardedvideo).

Каждый запрос получает ID; callbacks другого или завершённого запроса и повторные подтверждения игнорируются. Пауза начинается до открытия видео и остаётся до завершения запроса. Она независима от пауз SDK, видимости и фокуса. Время ожидания видео исключается из следующего офлайн-накопления; завершённая выплата сохраняется даже при перезагрузке до `onClose`. Формат v11 и ключи сохранения не менялись.

50 проверок моста, 481 проверка правил и runtime-проверка Windows пройдены. В 25 сценариях собранного WebGL наградные callbacks подменены только внутри изолированного профиля теста; проверены настоящий canvas-ввод, вызов `.jslib`, сохранение выплаты, отмена, ошибка и перезагрузка до закрытия. Такой тест не подтверждает реальный рекламный показ или доход. В настоящем черновике 0.17 подтверждены запуск SDK и Game Ready; показ rewarded-видео пока не подтверждён.
