# Доступ к рейтингу 0.30.2

Тестовая выдача монет, опыта или жетонов больше не исключает сохранение из общей таблицы ММР. Старое поле `ratingTestProfile` оставлено в схеме v16 для совместимости, но при загрузке устанавливается в false. Все накопленные показатели и сам ММР сохраняются. Сброс шахты не возвращает ограничение.

Контроллер отправляет результат без проверки этой пометки и без поля `test` в новом запросе. SDK-мост также принимает корректные запросы старого формата с `test: true`. Сообщение об исключении тестового профиля убрано из окна рейтинга.

Для отправки по-прежнему нужен вход в Яндекс. Запросы выполняются с прежним интервалом 30 секунд, меньший результат не заменяет больший серверный рекорд. Формула ММР не менялась: прямая выдача монет не записывается как добытый доход; последующая игровая добыча и реальные расходы жетонов/опыта учитываются прежним способом.

- `DemoTools.cs`, `ProjectSettings/ProjectSettings.asset` — версия 0.30.2.

## Проверка

Обнови черновик, войди в Яндекс, открой MMR и обнови таблицу. Сообщения «Тестовый прогресс» больше нет. Текущий локальный результат отправляется при превышении сохранённого рекорда. Если таблица была открыта до завершения отправки, обнови её после снятия таймера на кнопке.

[Окно рейтинга после снятия ограничения](images/rating-v0302.png).

Автотесты используют управляемые ответы SDK в изолированном профиле; настоящий результат аккаунта владельца вручную не отправлялся. [Отчёт](Verification.md).
