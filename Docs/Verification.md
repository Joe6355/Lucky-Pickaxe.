# Проверка версии 0.3

Проверено 24 октября 2026 в Unity 2022.3.47f1. Игровые расчёты версии 0.2 сохранены.

- Windows x64 Development Build: успешно, 0 ошибок и 0 предупреждений в отчёте BuildPipeline.
- 63 проверки правил: пройдены. Включают начисления, границы редкости, кузницу, урон, контракты, бонусы пластов, миграцию v1, чтение резервной копии и атомарность неудачного розыгрыша.
- 100 симуляций по 20 минут: пройдены. Условия и средние результаты — [Balance.md](Balance.md).
- Проверочный запуск собранного приложения: PASS, 0 ошибок/исключений/проваленных проверок.
- Проверены нажатия, удержание руды через события EventSystem, улучшения, выдача жетонов, контракт, скорость анимации, отключение звука, блокировка двойного запуска и три окружения.
- Кнопки помещаются в окна 320×640, 390×844 и 960×540; основной экран проверен при 480×960. Изображения получены из рендера Unity.
- Проверяются наличие трёх иллюстраций в сборке, кириллица в обоих начертаниях Manrope и высота текстовых блоков. Проверен контракт с большим числом добытых блоков.

Повторить: меню **Mine Loot → Build Windows demo**, затем команда запуска с `-demoSmokeTest` из README. Это программные проверки, без теста на Android-устройстве, браузерного SDK и оценки удобства реальными игроками. Качество звука на разных устройствах отдельно не проверялось.
