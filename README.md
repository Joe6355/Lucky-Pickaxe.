# Mine Loot — Unity demo 0.1

**Unity 2022.3.47f1** (revision `88c277b85d21`). Проект находится прямо в этом каталоге.

## Запуск

1. Unity Hub → Add → выбрать эту папку → открыть через **2022.3.47f1**.
2. Открыть `Assets/MineLoot/Scenes/Demo.unity` и нажать **Play**.
3. В кликере нажимать на руду; каждые 5 ударов дают жетон.
4. Улучшить кирку за монеты; переключиться на рулетку и запустить пять кирок.

Windows-сборка: `Builds/Windows/MineLoot.exe`. Для переноса нужна **вся** папка Windows, не только exe.

Если сцены ещё нет: меню **Mine Loot → Prepare demo scene**. Интерфейс создаётся при запуске компонентом `DemoController`; параметры расположения пока заданы в коде.

## Реализовано

- Кликер: 25 монет за удар, жетон за 5 ударов, улучшение дохода на 10.
- Рулетка: независимая кирка на каждый из 5 столбцов. Деревянная — 55%/1 блок, железная — 35%/2, алмазная — 10%/4.
- Анимация розыгрыша, удары кирок, частицы породы, сундуки и окно правил.
- Блок даёт 10 монет, сундук — 250. Разрушенные блоки сохраняются. Открытый столбец ждёт остальных; новый пласт начинается после открытия всех сундуков.
- Локальный прогресс через JSON в PlayerPrefs. Результат розыгрыша фиксируется перед анимацией, повторный запуск во время анимации блокируется.
- Масштабирование интерфейса под размер окна и Screen.safeArea. Управление мышью или касанием через uGUI.
- Собственные временные пиксельные изображения, генерируемые в коде.

## Структура

- `Assets/MineLoot/Scripts/MineGame.cs` — правила и данные прогресса, без зависимостей от сцены.
- `ProgressStore.cs` — локальное сохранение и загрузка.
- `DemoController.cs` — интерфейс и анимация.
- `PixelArt.cs` — временная графика.
- `DemoSmokeCheck.cs` — проверка собранного приложения по флагу `-demoSmokeTest`.
- `Assets/MineLoot/Editor/DemoTools.cs` — создание сцены, проверки правил, Windows-сборка.
- `_test-concept/` — локальные эксперименты, не подключены к Unity и исключены из Git.

## Проверки и сборка

В редакторе: **Mine Loot → Verify game rules** или **Mine Loot → Build Windows demo**.

Командная строка PowerShell:

```powershell
& 'C:\Program Files\Unity\Hub\Editor\2022.3.47f1\Editor\Unity.exe' -batchmode -nographics -quit -projectPath $PWD.Path -executeMethod DemoTools.VerifyAndBuild -logFile "$PWD\Logs\build.log"
```

Проверка сборки (использует новый тестовый прогресс, не изменяет сохранение игрока):

```powershell
Start-Process '.\Builds\Windows\MineLoot.exe' -ArgumentList '-demoSmokeTest', '-demoOutput', "$PWD\Logs", '-logFile', "$PWD\Logs\runtime.log" -WindowStyle Hidden -Wait
```

Результаты: `Logs/rules-check.json`, `Logs/build-summary.json`, `Logs/runtime-check.json`. Скриншоты проверочного запуска — `Logs/unity-*.png`.

## Ограничения

Это первая локальная демка. Числа перенесены из эскиза, долгосрочный баланс не настроен; новые пласты пока имеют одинаковую сложность. Стартовый прогресс: 1240 монет и 3 жетона. Нет коллекции кирок, офлайн-дохода, звука, рекламы, платежей, облачных сохранений и SDK магазинов. PlayerPrefs не предназначен для защиты от редактирования прогресса.

WebGL-модуль не установлен в найденной Unity 2022.3.47f1: браузерная сборка пока не сделана. Android-модуль найден, но APK и работа на устройстве пока не проверены. Перед публикацией нужны интеграция выбранной площадки и отдельная проверка её требований.
